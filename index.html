About Orvex AI

What is Orvex AI?

A next-generation behavioral risk intelligence engine built for real-world security environments.

🛡️

Orvex AI processes live video streams, identifies individuals as tracked objects, and continuously scores each person's behavior based on loitering, pacing, zone violations, erratic movement, crowd clustering, and more — all in real time.

Intelligent. Private. Actionable.

Unlike traditional CCTV systems, Orvex AI doesn't store faces or personal data. Instead, it uses COCO-SSD object detection to track movement patterns and derives behavioral signals that matter for security teams.

  • No facial recognition — fully GDPR-friendly surveillance
  • Works on any standard webcam or IP camera feed
  • Runs entirely in-browser using TensorFlow.js — no heavy server needed
  • Assigns unique Track IDs to each detected person across frames
  • Automated alert logging with timestamped event history
  • Zone-aware risk assessment with configurable thresholds
